SipLy POS Android App Project
=============================

This project wraps the SipLy POS into a native Android app shell.
Features already included in the local POS:
- Combos: Sip & Snack ₱79, Sip & Bite ₱89, Sip & Crunch ₱109
- Regular milk tea: 12oz ₱49, 16oz ₱59, 22oz ₱69
- Side dishes and flavors
- Sales records stored on the device using localStorage

To create the APK, open this project in Android Studio and Build > Build APK(s).
The resulting APK will be under app/build/outputs/apk/debug/.

Note: This environment does not have the Android SDK/Gradle build tools installed,
so I created the complete Android Studio project but cannot truthfully attach a
compiled APK from here.
